# Проект "Домашнее задание 11_2"

## Описание:

Проект "Домашнее задание 11_2" включает в себя следующее задание:  разработать декоратор, который будет 
автоматически регистрировать детали выполнения функций, такие как время вызова, имя функции, 
передаваемые аргументы, результат выполнения и информация об ошибках.

## Установка:

Клонируйте репозиторий:
```
git clone https://github.com/ValeriyaChulkovaa/project-x.git
```

Установите зависимости:
```
pip install -r requirements.txt
```

## Функуии:

@log - Декоратор который логирует результат вызова функции в консоль если аргумент не задан или в файл. 
Пример: @log() -> без аргумента, вывод будет в консоль. 
Пример: @log(filename='test_log.txt') -> аргумент передан, вывод будет записан в файл test_log.txt

## Тесты:

1. Тест test_log_terminal_ok() проверяет работоспособность функции
2. Тест test_log_terminal_error() првоеряет выдачу ошибки
